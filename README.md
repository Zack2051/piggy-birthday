# 把喜歡，寫成一份禮物。

手機與桌面適用的生日互動網頁。純 HTML / CSS / JavaScript，沒有套件、帳號或外部服務，離線也能使用。

## 打開

直接用 Chrome、Edge 或 Safari 開啟 `index.html` 即可，不需要安裝或建置。

## 換成你們的故事

編輯 `content.js`：

- `name`、`sender`：女友的暱稱與你的署名。
- `chapters`：三個回憶關卡，可自行增減（至少留一關）。`correct` 從 0 開始計算，設為 `null` 代表每個答案都可以。
- `hint`：答不出來時的小提示。
- `memoryTitle`、`memory`：翻開卡片後的標題與心意。
- `photo`：預設無照片，填入例如 `photos/date.jpg`，並把照片放進對應資料夾。找不到圖片時會自動隱藏圖片。
- `letter`：信件段落，每段一個字串。
- `wish`：許願後的生日祝福。
- `giftName`、`giftMessage`、`gift`：禮物名稱、拍立得吐出的小相片文字、禮物介紹。目前是拍立得插畫，搭配「希望你能用這個紀錄每一天的豬生活」。插畫是示意外觀，並非特定品牌或型號。

保留字串外面的引號；文字中若要寫雙引號，使用 `\"`。換行可使用 `\n`。

## 體驗流程

封面 → 三段回憶問答 → 每關翻開心意卡片 → 恭喜過關與愛心獎章 → 按下「收下你的心意」，播放約 1.2 秒的禮物送達動畫 → 點開禮物盒，拍立得升起並吐出小相片 → 生日信與許願祝福。
包含封面浮動、燭火、選項依序進場、卡片翻轉、盒蓋彈開及紙花動畫；重玩時禮物盒會復原。
答錯能再試、有提示、最後一題所有答案皆可通過。支援鍵盤操作及系統減少動態效果設定。

此版本沒有發布到網路。要傳給對方離線使用，請將整個 birthday 資料夾一起打包；若要手機點連結即開，需另外部署靜態網站。

生日信採用暖色信紙、橫線、郵戳與封蠟裝飾；文字仍在 `content.js` 的 `letter` 編輯，署名使用 `sender`。
